## §1. 核心科学问题与证据性质

**Q1 可执行性：** 给定真实完整状态，能否找到合法 z 的连续控制序列，在真正有伙伴推进时同时保持任务效果、低风险、合理 yaw/支撑及停止恢复？分别检验瞬时动作、1–3秒维持、因果反馈重规划，不能互相替代。

**Q2 学习机制：** 如果存在这样的响应，BC500/v2B/v3策略为何不能稳定调用？区分未探索到、优势信用/优化保留不足、真实闭环传播和底座低层动作质量。不得凭一次GAE符号不一致判critic实现bug。

**Q3 定价 vs 可控性：** 同一实际候选上旧reward/v3reward的排序是否匹配独立物理质量？有合格可执行解但训练未利用，是定价或学习问题；当前预算内未发现解，只能提高“接触条件化低层适配”假设优先级，不能给出绝对不可达证明。

**Q4 可辨识性：** 在10N力限幅下，不同隐藏伙伴状态能否产生相同的全部受限观测历史、但需要实质不同的有益响应？如果不能验证响应需求有差异，不能宣称控制相关的观测别名。

结论统一分级：**已证实 / 与证据相容 / 未证**，关键因果主张标注实际同状态反事实、预算、时域、信息级别与独立父组数。

### §3.1 固定状态集与资格

必须覆盖：
- **有限正控制**：v3包一的2个严格有效持续状态与合适的原生站立、手臂、前进/停止能力正控制；小幅上肢/腰部成功不当接触walking成功。

- **旧32回归取舍**：包括stop/continue旧B128相对v3-128的明确误差/力退化，及必要的同条件中距取舍。
- **阶段与源**：standing near/mid、持续/保持、停止前/减速/停止保持、释放恢复（若评价时域覆盖）；可纳入历史 arm-ready/moving 作为明确域外能力探针，但不能与 v3 standing 主分布混合成晋级统计。
- **stop/continue共同前缀**：停止分叉之前完整机器人、伙伴、动作/力历史及RNG复现一致；停止信号实际变得可观测之后才允许因果控制分叉。stop和continue合为**一个父组**。

状态固定后才运行 L1 搜索；F1的状态是历史已暴露/诊断域，**非独立封存泛化实验**。各状态标注 dev / exposed / stress / source-positive，不拿域外压力测试计总体胜率。

### §3.2 饱和力观测别名：独立一组，不计能力成功率

构造一个**受控的隐藏状态反事实对**，仅用于观测可辨识性，不假装是两条自然独立历史轨迹：

- 保持**同一完整机器人状态与自身历史**：q/dq、last-z、上一动作/PD、BFM输入历史、可部署接触力历史、已知接触安装位置、同一个 guidance mode 和相同受限内部记忆；当前伙伴隐藏anchor分别置于不同位置。
- 两个隐藏anchor必须使当前**受限观测完全相同**（按实际输入编码及归一化核验），世界/本体系施力同向且同为10N饱和；真实隐藏anchor不得泄漏到 actor、C-S搜索器和其评分。
- 明确此为在快照时刻改变隐藏伙伴变量的**干预拼接**，不能同时声称两个分支拥有完全相同的真实伙伴过去轨迹。检查初始物理一致性、无不合法瞬间冲量/回调泄漏；不能构造则标记未实现，不伪造。
- 首先利用独立的 **C-P 或 O-F 特权参考**检验两种隐藏状态是否真的需要**不同且具有非平凡收益差距的响应**：例如一个响应在A状态显著优于B响应、而B状态反之；在相同任务/预算和真实物理质量条件下配对，报告判定余量及搜索不确定性。只有证明这一点，才可称**控制相关观测别名**。
- 即使当前最佳响应不同，还须检查机器人动作后未来力观测是否会迅速消歧；不可由t时刻别名直接断言全回合C-S控制不可实现，允许主动试探和后续反馈。
- **统计身份为1个额外父组，2个相关干预分支，单独汇报；不入L1/L2能力成功率、超限父组比例或任何独立成功统计。** 不得因成功构造两个anchor而宣称“已经证明控制所需信息缺失”。

## §5. L0–L3统一实验阶段与信息级别

### §5.0 信息权限字段矩阵（C-S / C-P / O-F）

定义三个**严格不同**的信息级别，按一次候选选择过程中**信息最强的组件**判定，包括候选生成、伙伴预测器、模拟器初始化、评分函数、选择器及外部人工调参，不能只看Actor输入。

| 字段/权限 | C-S：因果受限 sensing | C-P：因果特权 privileged | O-F：oracle future |
|---|---|---|---|
| 本体q/dq、IMU、关节/动作/last-z历史、已知接触安装位置 | 可 | 可 | 可 |
| 当前/历史**可部署等价**的力/力矩测量、合法任务或guidance mode | 可 | 可 | 可 |
| 仿真特权真值：当前partner anchor、真实partner velocity、当前接触激活、当前未测量几何误差 | **不可** | 可，仅当前/过去 | 可 |
| 真正的未来anchor/停止时刻、future partner trajectory、未来partner RNG/隐藏scenario spec | **不可** | **不可** | 可，须标记 |
| 伙伴预测器输入 | 只允许C-S历史与事先公开的固定模型参数 | 允许当前/过去特权，**不得使用真实未来** | 可含未来真值 |
| 候选评分时的anchor误差、伙伴进度和真实状态 | **不能读取隐藏真值**；只能用可观测反馈或仅由C-S历史估计出的量 | 可读取当前特权真值及由其因果预测得到的后果 | 可读取真实未来后果 |
| 在真实完整隐藏状态上重置模拟器并多分支查询 | **不能冒称C-S可部署搜索**；若用于候选选择，按其所用隐状态/未来信息升级 | 可用当前特权状态 + 仅因果伙伴预测，标记 privileged simulation | 若重放精确未来anchor/真实未来伙伴程序，标记O-F |
| 最终真实物理评估报告 | 可在**选定候选后**独立用全部真值评分；该真值不得回流进C-S选择/调参 | 同左 | 同左 |

**两条明文防泄漏规则：**
1. **评分泄漏：** 纵使Actor与候选生成器不读隐藏partner anchor，只要优化候选的reward/score/过滤/早停用真实anchor误差或真实partner progress，该搜索就**不是C-S**；使用当前/过去真值最低标为C-P，使用真实未来标O-F。事后用于独立科学评分不算候选选择，但必须保证结果没有反向反馈给选择器。
2. **模拟器未来泄漏：** 如果候选rollout调用了原场景真实未来anchor生成器、真实未来停止时刻、预存未来轨迹或可精确重放未来partner随机流，随后把这条真实未来包装成“模型预测”，必须标 **O-F**。禁止用“预测器”名称掩盖oracle；固定已知K/D本身不构成未来oracle。

进一步约束：用于C-S的内部预测器可以事先训练，但**本轮运行时输入、模型版本、训练来源和运行时每个实际查询**必须可审查。若尚无合格C-S前向预测器，不得临时借真实仿真未来补成C-S；可只做C-P/O-F上界并诚实留下C-S缺格。仿真理想力观测不自动等于已验证的G1传感器，应标注 `ideal-force proxy`。

**查询级证据字段**至少包含 `information_tier`、`actor_observation_schema`、`candidate_generator_inputs`、`partner_predictor_version`、`partner_predictor_inputs`、`score_features`、`simulator_state_origin`、`future_anchor_accessible`、`future_anchor_consumed`、`anchor_error_used_in_selection`、`selection_horizon`、`physical_eval_horizon`、`query_wall_seconds`、`state_parent_id`、`state_snapshot_sha`、`actual_runtime_sha`。若某字段缺失，不能获得C-S资格。

### §5.3 L2｜1–3秒闭环重规划与因果信息分层（预算4h）

- 每100ms实际执行合法z首段，读取更新后的真实可用观测，再选择下一命令；若底层物理控制以20/5ms推进，时间对齐必须维持既有合同。
- 对相同状态/伙伴过程，分别报告**C-S**固定/可行因果受限控制，以及**C-P**使用当前特权状态但不读未来的反馈搜索；若某层未实现可验证预测器，保留缺格。不能在候选评分中使用真实未来并自称C-P。
- C-S最基本固定对照可以是已验证权限的BC500等历史受限策略；特权高层网络不能仅靠“把输入清零”冒称可靠受限Student。若没有合格学习型C-S planner，写明限制，不以本阶段任务强制重训一个预测器。
- 为每个候选及每次重规划存储 §5.0 全部权限字段。特权搜索成功只能证明可获得特权的控制上界，**不能宣称可部署**。
- **stop/continue**：分叉前受限策略的已观察前缀必须逐值一致；分叉后再根据可观测反馈响应。对特权搜索若使用停止真值，升级O-F。
- 比较L1预定序列与L2反馈重规划在同状态下的任务、slip/yaw、根部进展与恢复；声明阶段、独立父组和搜索计算成本。搜索耗时若远大于100ms必须说“离线反馈能力”，不能当实时可部署算法。

### §5.4 L3｜正式进入报告点后才可启动的针对性上界/扩展（预算3h，默认禁用）

经批准后，L3只可从下列必要增量中选定一项或有限组合：O-F未来可见条件上界、较长完整stop/release恢复时域、饱和力别名的控制相关性验证或关键失败域额外候选饱和性检查。不得把L3变成无界latent搜索、多任务大训练或奖励参数扫描。无L3亦可完成F1结论。

## §6. 物理指标、成功资格与滑移语义

所有结论按相同父组/状态、实际阶段报告：真实腕XYZ跟随误差、世界系接触点/伙伴进度、F_XYZ RMS与10N cap占比；root X/XY、pelvis/torso/yaw、手臂相对肩及躯干参与、支撑与脚步、loaded slip、法向力/接触body与点、真实q/dq/torque、q_PD连续性、硬边界、停止/撤力后恢复。不允许用q_PD峰值冒充真实关节瞬时运动。

原绝对M1任务参考与旧相对风险门**分别**报告；near≤4cm/4N、mid≤8cm/7N、stop保持≤8cm/6.5N等作为对应有限诊断参考，且同时要求实际伙伴推进、非停住换低力。有限1–3秒窗口通过不等于完整回合/新封存通过。原10N/K80D8、关节真实边界和既有stop/continue物理定义不改。

滑移分三列：**旧风险事件**（保留原加载>1e−6N、.45m/s阈值、整个不利阶段）；**持续真实支撑滑移**（带载时长、前后积分速度、累计接触点切向位移及载荷/支撑分类）；**带载落脚瞬态**（法向力、冲击和后继速度）。不通过删掉69/79步后消解事件、抬载荷门或裁剪时段谋取“改善”。事件严重度减少≠持续滑移必然减少。

一次候选要称为“合格持续控制”，必须把任务/推进、质量/yaw/支撑和相应时域一起列出。不能强制固定“先臂后脚”或最少迈步数；合理局部响应也可以成功。

## §7. 奖励、学习与能力判读矩阵（不改v3合同）

对**同一真实候选轨迹**独立离线重算v2原reward、v3 λ=.33 reward与正确物理时间折扣回报，并同时评估独立真实物理质量。旧连续slip与v3离散事件项不同单位，不重复乘dt或漏项；不得调整lambda、奖励公式或原选模，并不能靠离线奖励排序反写旧模型。

| 同状态真实证据 | 较支持的解释 | 明确不能推出 |
|---|---|---|
| 存在任务好且低slip/yaw的连续控制；旧/v3奖励反而偏好质量差的候选 | 定价/奖励排序问题 | PPO失败只由reward引起 |
| 合格控制存在、奖励正确偏好，但训练政策没有稳定输出；历史样本/GAE/参数保留也有缺口 | 探索、时序信用、参数更新或状态覆盖问题 | 唯一critic实现错误 |
| v3减少超限父组但更重尾部、stop/yaw劣化 | 多指标取舍、风险事件的时序/语义差异 | 新λ取得共同质量胜出 |
| 单步方向有效，L1多步或L2执行不能维持 | 连续控制/步态组织/状态恢复缺口 | 冻结BFM完全不可控 |
| L2的C-P成功、C-S失败 | 观测/预测/控制优化权限可能受限 | 仅凭差距证明信息论不可观测 |
| 只有O-F成功 | 未来信息或预测依赖可能重要 | 可部署Student可模仿oracle |
| 多来源、多时域有界搜索仍找不到任务与质量双合格，原生运动质量亦有限 | 接触条件化低层执行能力不足更值得优先测试 | 所有256D合法z理论上不存在解 |
| 饱和别名在同一受限观测下，通过特权反事实证明需不同高收益响应 | 控制相关信息别名（须注明时域、干预与主动感知可能） | 全回合C-S控制绝对不可能 |

尤其注意：**有界搜索成功是局部存在性证据；失败仅是给定状态/候选空间/算法/预算/信息级别下未发现解。** 任何推论不得超出样本和权限级别。

## §8. 搜索覆盖、充分性与失败退出
