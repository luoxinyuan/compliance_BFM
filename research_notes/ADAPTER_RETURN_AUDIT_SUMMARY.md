# Adapter Return-to-Prior 只读审计｜关键结论

事实基准9441ec3；原V1物理资格失败不变。本轮只读存档与CPU前向/梯度计算：**新物理0、新优化步0、CUDA初始化0**。未改实验代码、reward、Envelope、滑移判据、封存、原模型或账本。

**判断：有明确的机制缺口，值得审阅一次小型、条件化的B-only学习试验；不支持重启完整B/C。**

1. **现有CPR不是同z的adapter归零约束。** `agent.py:122–124` 当前策略重算z后动作，对比原BFM在存档native z上的动作。冻结B19复核实际被采到的495个原生状态：全部z不同，中位夹角3.679°。混合z动作误差RMS中位.00578rad，同z adapter修正.00670rad；存在两路补偿。它可以保护原生总行为，不能证明adapter在恢复域回归原生动作。
2. **数据有恢复，约束却不同域。** B19 replay4750条中有1850条释放后状态=37秒；实际被抽414次，347个唯一状态，跨8个父组。CPR池760条全是原生standing前缀，没有策略访问的恢复状态。具体失败父组释放后50条只抽到1次（update37/11.72s/slot1），不是“所有恢复都没练”，是特定失稳域覆盖薄且缺直接动作保持。
3. **物理归因支持adapter重要，但不是唯一解释。** 现有完整同状态off干预保留U后能恢复；原on约.51s撞界。原on多关节adapter修正RMS中位.236rad（左踝pitch均值−.339rad），第一公共状态当前U单独造成的原BFM qPD变化RMS约.024rad。V1仍有约.103rad持续修正，3秒末root速度.203m/s，off约.00469m/s；滑移失败照旧。CPU分解是同状态敏感性，不代替新物理因果试验。
4. **这一恢复窗reward认可更好的动作，Q局部偏好却相反。** 同3秒实际折扣回报off−.276、V1−1.011；冻结Q首状态base .24995、V1动作.25646。Q读数与有限窗物理回报不等价，不能据此宣布critic bug；但它支持继续查Q的外推/信用质量，而不是先改reward。
5. **简单追加执行后Return也有梯度问题。** 同一状态约79.3%的adapter输出受原Envelope饱和，执行后Return梯度为0；不是断图bug，参数总梯度仍非零。草案建议惩罚投影前raw修正的关节尺度代理，执行、critic和replay仍用原V1实际动作。固定系数候选.0008：来自该状态约2倍任务梯度尺度的只读校准，非扫参或已证明最优。

**反证与边界：** 早期8回合恢复原本良好；base-off仍不满足绝对slip/yaw参考；同z不能修复坏z/坏历史；无接触时某些非零adapter可能用于平衡或正常收步。只有一个原始失败状态有明确off物理恢复证据，不能据此给全部inactive行贴“该回归原生”标签。

**待审阅最小方案（未运行）：** 两个B19克隆，同一数据/Adam/64次adapter更新；共同冻结U/Q/鉴别器，唯一差别为λ_R=0或.0008，仅用于隔离adapter恢复机制，不冒充原完整B训练。拟先核验两个恢复训练父组（目前只有B19该状态有现成off证据），另有六个不同父组做恢复/active/none回归；新Return标签只来自合格base-off实际轨迹。先验证独立恢复域，不成立就不训练。执行仍用旧V1；验收仍用原§4滑移等物理门。建议新上限2 job小时/2GiB，含最多30个3s实际分支、128个adapter优化步和失败/IO；**须另行批准，不自动执行**。若只降训练loss而独立物理恢复/active不共存，结束当前Return配方，不再加系数或轮数。
