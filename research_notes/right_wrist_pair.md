## Interpretation and first scientific boundary

**Stable closed-loop response is observed in this single small-load trial.** The original frozen actor changes its outputs, actual wrist/root/foot-load behavior changes, and no fall occurs. This is stronger evidence than a token/reference change alone. It does **not** causally establish active assistance, useful intent following, a contact expert, broad stability, or LPP efficacy: passive deflection, existing joint impedance and policy feedback are not separated by this pair.

The first scientific confound is the original reset-fixed anchor. By contact activation the no-force wrist has drifted approximately [-62.91,-48.22,-46.41] mm from that anchor. Consequently, first applied force is [3.257,2.803,2.557] N, at the 5 N cap. This condition is not a pure +X force or a clean 3 cm tracking command, and 80*0.03=2.4 N is only a nominal excursion scale. Active-period mean force is [2.773,2.267,2.101] N, active RMS 4.17846 N; 34 of 701 active samples hit the cap (4.85%, 2.83% of all samples). Late-hold anchor error is still 51.16 mm versus no-force 107.55 mm. The existing `settling_time=0` metric uses a 5 N threshold equal to this pilot's cap, so it is uninformative and must not be used as successful force relief.

**Next smallest experiment (not executed):** keep the same recovered controller, seed, cap and timing, but supply an explicit Tether trajectory whose origin is the already measured no-force wrist position at 1 s, then move that anchor +3 cm. The original `Tether.reset(..., trajectory=...)` already supports this without changing WBC or shared code. This removes initial position preload; damping and subsequent cross-axis motion must still be logged, so it does not guarantee a pure +X force. Compare with the same matched no-force baseline. A later bounded original-action replay ablation could separate feedback contribution from passive/PD response; do not label the current pair that ablation. No training is warranted by this pilot alone.
