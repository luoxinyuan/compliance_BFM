# 可比性与评价修订
变更仅用于新的短距方向实验，全部历史结论保留。

1. 硬物理安全、真实执行/恢复、无未来输入、源身份为正确性要求。机器人凡挪脚、腕高不对称、足底材料点越某个描述阈值、没有先伸手均不能单独宣判接触任务失败。报告实际腕相对肩/躯干及世界位移、root路径、支撑与滑移、双腕和姿态、释放恢复。原生运动项可与交互收益存在取舍。
2. 零外力在关闭施力臂逐tick核验。仍连接的静止伙伴允许姿态诱发真实受力；释放时速度与身体历史保留。断开后位置成本为零，不看旧anchor作为成功标准。无力静站和原生运动分别报告；“身体完全不动”不作为统一目标。
3. 原方向门已替换，见LOCK。世界X、1N筛选、要求所有5ms力方向一致都不再作为硬门；全移动窗口的真实力同时报告。角度和方向比较只检验指定的方向提示是否真的可区分，并非要求机器人手沿一条直线、每帧复刻伙伴。出现背景主导/实际无可辨别信号，保留为刺激不足；绝对力与配对背景修正值均留档。15°不冒充第四独立祖先。祖先身份排重。
4. 旧草案的共同前缀 assert 只检查固定125个qpos；改为对完整共同外生伙伴前缀（第一处命令位置或速度不同前的全部时刻）检查初始真实状态、RNG、实际可见输入、执行命令、实际力与状态。对于5ms步尾状态与控制起点，分别按相同时刻对齐。必须记录真实分叉时刻，不以固定帧数代替。分叉后才评估方向差异。
5. 两个策略出现物理差异不必分出胜负。旧1cm/0.5N仅是存档复核的最小差异口径，不能作为训练达标门。误差、力、相反方向的实际腕/肩响应、零需求及恢复并列报告，覆盖不足记不可判。位置跟随进入评价，含位置项的排序与其相关有定义上的原因；数据不是人类偏好的独立标签。
6. 训练诊断按完整实际回合/固定方向等权，使用同一窗口、同一单位及分项；同时报告有力期间均值和含保持/释放的阶段结果。禁止短回合或零力样本占比提高制造虚假reward增长。仅当Actor开始更新、关键条件已覆盖、相同固定来源/路径的均值执行和采样表现均有可判变化范围时，才允许作平台期判断。原草案实际仅两个更新后开发节点；证据不足可按原预算终止，但不得当作收敛/学习无效的证据。方法数值回归单独检查。训练后应以当前策略单独实际执行g=0原生回归，不从采集时冻结B0的输出推断保留。
